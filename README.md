# مقایسه دو فایل اکسل (تک‌فایل HTML)

یک صفحهٔ **کاملاً استاتیک** که دو فایل اکسل را در مرورگر می‌خواند، مقایسه می‌کند و تفاوت‌ها را همان‌جا نشان می‌دهد. **سرور، نصب، یا اینترنت لازم نیست** (کتابخانهٔ خواندن اکسل داخل همان فایل HTML قرار دارد).

## استفاده

1. فایل [`excel-compare.html`](excel-compare.html) را دانلود کنید (یا از همین مخزن کپی بگیرید).
2. روی فایل دوبار کلیک کنید یا آن را در Chrome، Edge یا Firefox باز کنید.
3. **فایل اول** و **فایل دوم** را انتخاب کنید.
4. شیت مشترک را انتخاب کنید و روی **مقایسه** بزنید.

فرمت‌های پشتیبانی‌شده: `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.ods`, `.csv`

## گزینه‌ها

| گزینه | توضیح |
|--------|--------|
| **ستون کلید** | اگر پر شود، سطرها بر اساس آن ستون جفت می‌شوند (مثلاً کد کالا). اگر خالی باشد، مقایسه **سطر به سطر** است. |
| **ردیف عنوان** | شمارهٔ سطر سرستون‌ها (معمولاً `1`). با `0` همهٔ سطرها داده محسوب می‌شوند. |
| **دانلود گزارش CSV** | بعد از مقایسه، خروجی تفاوت‌ها را ذخیره می‌کند. |

## حریم خصوصی

پردازش فقط روی دستگاه شما انجام می‌شود؛ فایل‌ها به هیچ سروری ارسال نمی‌شوند.

## ساخت مجدد فایل HTML (اختیاری)

اگر `build-html.py` یا نسخهٔ SheetJS را عوض کردید:

```bash
curl -sL "https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.mini.min.js" -o xlsx.mini.min.js
python3 build-html.py
```

خروجی: `excel-compare.html`
